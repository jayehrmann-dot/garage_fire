# Garage Fire

Early-morning garage fire. Aim the hose and hold the button to set how far the water reaches.
Needs a terminal of at least 80 columns x 23 rows.

```bash
./play.sh
```

| Key | Action |
|---|---|
| Up / Down or W / S | Aim nozzle up / down |
| Left / Right or A / D | Walk firefighter back / forward |
| SPACE (hold) | Spray. The longer you hold, the longer the stream; let go and it retracts |
| P | Pause |
| Q / Esc | Quit |

Water arcs under gravity, so reaching far or high needs both angle and reach.
The tank drains while spraying and refills when idle. Put out every fire before
the garage burns down; each level adds more fires that grow faster.
